# 開源授權條款

Konado 採用多授權條款模式。使用或散佈 Konado 時，可依專案需求任選以下一種授權條款：

- [MIT 授權條款](https://github.com/godothub/konado/blob/main/LICENSE)：限制最少，適合一般商業與開源專案
- [BSD 3-Clause 授權條款](https://github.com/godothub/konado/blob/main/LICENSE-BSD)：額外禁止使用著作權人或貢獻者名稱為衍生產品背書
- [木蘭寬鬆授權條款 2.0](https://github.com/godothub/konado/blob/main/LICENSE-MULANPSL)：包含明確的專利授權條款

## 散佈要求

請保留所選授權條款要求的著作權聲明、授權條款全文與免責聲明。通常可放在發行包的第三方授權條款檔案、關於頁面或產品隨附文件中；授權條款並不強制要求在遊戲啟動畫面顯示 Konado 標誌。

若修改或重新散佈插件，也請檢查專案內字型、圖片及其他第三方資源各自的授權條款。本頁僅概述倉庫的授權方式，不構成法律意見；實際使用以對應授權條款原文為準。
