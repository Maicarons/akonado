# Konado .NET API

Konado .NET API 是 Konado 的 C# 擴充層。

它主要提供：

- `KonadoApi` 自動載入入口
- `DialogueManagerApi` 對話管理器控制介面
- Konado 對話流程事件監聽
- KonadoScript 本地化路徑解析與載入
- 對話變數與存檔管理
- `.ks` 腳本編譯介面
- `KonadoShot`、`KonadoProgram`、`KonadoInstruction` 等執行資料包裝類別

請先閱讀安裝說明，再查看 API 參考。
