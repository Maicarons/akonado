# 屏幕文本

## 功能描述

屏幕文本（NVL Overlay）用于显示视觉小说中的全屏正文文本，不以对话框形式呈现，而是以覆盖层的方式展示在屏幕中央区域，适合用于旁白、场景描述、内心独白等大段文本展示场景。

## 语法结构

```text
screentext {
    "文本行1"
    "文本行2"
    ...
}
```

## 参数说明

| 参数 | 必需 | 示例 | 说明 |
|------|------|------|------|
| 文本行 | 是 | `"暴风雨越来越猛烈了..."` | 要显示的文本行，每行一个字符串字面量 |

- 文本行数量不限，至少需要一行
- 每行文本用双引号包裹，每行一句
- 文本行按顺序逐行显示，带有淡入动画效果
- 每行显示完成后，在最后一个字符右下角会显示闪烁的三角箭头指示器，点击后播放下一行
- 确认最后一行后，覆盖层会先淡出，再继续执行下一条指令

## 示例

```text
# 显示全屏正文
screentext {
    "暴风雨越来越猛烈了..."
    "狂风呼啸，电闪雷鸣"
}

# 单行文本
screentext {
    "夜深了，四周一片寂静"
}
```
