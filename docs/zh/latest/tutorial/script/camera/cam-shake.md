# 镜头晃动

## 功能描述

使镜头产生随机抖动效果，模拟地震、爆炸或紧张场景的视觉效果。

## 语法结构

```text
cam shake [持续时间]
```

## 参数详解

| 参数 | 必需 | 示例 | 说明 |
|------|------|------|------|
| 持续时间 | 否 | `1.0` / `2.5` | 晃动持续时间（秒），默认值为 `1.0` |

## 效果说明

- 晃动强度随时间逐渐减弱（从强到弱）
- 晃动结束后镜头自动恢复到晃动前的位置
- 晃动期间会在当前镜头位置周围产生随机偏移

## 示例

```text
cam shake
cam shake 1.0
cam shake 2.5
```
