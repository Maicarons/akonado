# 对话框显示/隐藏

## 功能描述

用于在脚本中控制对话框的显示与隐藏，支持自定义淡入淡出动画时长。动画播放期间会等待完成后再自动执行下一句对话。

## 语法结构

```text
showtextbox [duration]
hidetextbox [duration]
```

## 参数说明

| 参数 | 必需 | 示例 | 说明 |
|------|------|------|------|
| duration | 否 | `1.0` | 淡入/淡出动画时长（秒）；省略或设为 `0.0` 时立即显示/隐藏 |

- `duration` 可以省略，不能为负数
- 设为 `0.0` 时禁用动画，立即显示/隐藏，不会产生等待延迟
- `duration` 大于 `0.0` 时播放透明度淡入/淡出动画，等待动画完成后自动执行下一句
- `hidetextbox` 隐藏完成后会清除当前角色名和对话文本，避免下次显示时短暂出现上一句内容

## 示例

```text
# 用 1 秒淡入动画显示对话框
showtextbox 1.0

# 用 0.5 秒淡出动画隐藏对话框
hidetextbox 0.5

# 禁用动画，立即显示对话框
showtextbox 0.0

# 禁用动画，立即隐藏对话框
hidetextbox 0.0

```
