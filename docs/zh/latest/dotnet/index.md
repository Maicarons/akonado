# Konado .NET API

Konado .NET API 是 Konado 的 C# 扩展层

它主要提供：

- `KonadoApi` 自动加载入口
- `DialogueManagerApi` 对话管理器控制接口
- Konado 对话流程事件监听
- KonadoScript 本地化路径解析与加载
- 对话变量与存档管理
- `.ks` 脚本编译接口
- `KonadoShot`、`KonadoProgram`、`KonadoInstruction` 等运行数据包装类

请先阅读安装说明，再查看 API 参考。
