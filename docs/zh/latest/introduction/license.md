# 开源许可证

Konado 采用多许可证模式。使用或分发 Konado 时，可根据项目需求任选以下一种许可证：

- [MIT 许可证](https://github.com/godothub/konado/blob/main/LICENSE)：限制最少，适合常规商业与开源项目
- [BSD 3-Clause 许可证](https://github.com/godothub/konado/blob/main/LICENSE-BSD)：额外禁止使用版权方或贡献者名称为衍生产品背书
- [木兰宽松许可证 2.0](https://github.com/godothub/konado/blob/main/LICENSE-MULANPSL)：包含明确的专利许可条款

## 分发要求

请保留所选许可证要求的版权声明、许可证正文和免责声明。通常可以把它们放在发行包的第三方许可证文件、关于页面或产品随附文档中；许可证并不强制要求在游戏启动画面展示 Konado 标识。

如果修改或重新分发插件，请同时检查项目中字体、图片和其他第三方资源各自的许可证。本页仅概述仓库的许可方式，不构成法律意见；实际使用以对应许可证原文为准。
