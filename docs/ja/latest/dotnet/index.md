# Konado .NET API

Konado .NET API は Konado の C# 拡張レイヤーです。

主な機能:

- `KonadoApi` 自動読み込み入口
- `DialogueManagerApi` による会話マネージャー制御
- Konado 会話フローイベントの購読
- KonadoScript のローカライズパス解決と読み込み
- 会話変数とセーブデータの管理
- `.ks` スクリプトのコンパイル
- `KonadoShot`、`KonadoProgram`、`KonadoInstruction` などのランタイムデータラッパー

まずインストールガイドを読み、その後 API リファレンスを確認してください。
