# オープンソースライセンス

Konado はマルチライセンス方式を採用しています。Konado を利用または再配布する際は、プロジェクトの要件に応じて次のいずれか一つを選択できます。

- [MIT License](https://github.com/godothub/konado/blob/main/LICENSE)：制約が最も少なく、一般的な商用・オープンソースプロジェクトに適しています
- [BSD 3-Clause License](https://github.com/godothub/konado/blob/main/LICENSE-BSD)：著作権者や貢献者の名前を派生製品の推奨に使用することを追加で禁止します
- [Mulan PSL v2](https://github.com/godothub/konado/blob/main/LICENSE-MULANPSL)：明示的な特許許諾を含みます

## 再配布時の要件

選択したライセンスが求める著作権表示、ライセンス全文、免責事項を保持してください。通常は、配布物の第三者ライセンスファイル、About 画面、または製品付属文書に収録できます。ゲームの起動画面に Konado のロゴを表示することは、いずれのライセンスでも必須ではありません。

プラグインを変更または再配布する場合は、プロジェクト内のフォント、画像、その他の第三者アセットに適用される個別ライセンスも確認してください。本ページはリポジトリのライセンス方式の概要であり、法的助言ではありません。実際の利用条件は選択したライセンス原文に従います。
