# 오픈 소스 라이선스

Konado는 다중 라이선스 방식을 사용합니다. Konado를 사용하거나 재배포할 때 프로젝트 요구 사항에 따라 다음 중 하나를 선택할 수 있습니다.

- [MIT License](https://github.com/godothub/konado/blob/main/LICENSE): 제한이 가장 적어 일반적인 상업 및 오픈 소스 프로젝트에 적합합니다
- [BSD 3-Clause License](https://github.com/godothub/konado/blob/main/LICENSE-BSD): 저작권자 또는 기여자의 이름을 파생 제품의 보증에 사용하는 것을 추가로 금지합니다
- [Mulan PSL v2](https://github.com/godothub/konado/blob/main/LICENSE-MULANPSL): 명시적인 특허 사용 허가를 포함합니다

## 재배포 요구 사항

선택한 라이선스에서 요구하는 저작권 고지, 라이선스 전문, 면책 조항을 유지하세요. 일반적으로 배포물의 제3자 라이선스 파일, 정보 화면 또는 제품과 함께 제공되는 문서에 포함할 수 있습니다. 어떤 라이선스도 게임 시작 화면에 Konado 브랜드를 표시하도록 강제하지 않습니다.

플러그인을 수정하거나 재배포할 때는 프로젝트에 포함된 글꼴, 이미지 및 기타 제3자 에셋의 개별 라이선스도 확인하세요. 이 페이지는 저장소의 라이선스 방식을 요약한 것이며 법률 자문이 아닙니다. 실제 사용 조건은 선택한 라이선스 원문을 따릅니다.
