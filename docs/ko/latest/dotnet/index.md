# Konado .NET API

Konado .NET API는 Konado의 C# 확장 레이어입니다.

주요 기능:

- `KonadoApi` 자동 로드 진입점
- `DialogueManagerApi` 대화 관리자 제어
- Konado 대화 흐름 이벤트 구독
- KonadoScript 현지화 경로 확인 및 로드
- 대화 변수 및 저장 데이터 관리
- `.ks` 스크립트 컴파일
- `KonadoShot`, `KonadoProgram`, `KonadoInstruction` 같은 런타임 데이터 래퍼

먼저 설치 문서를 읽고, 그다음 API 참조를 확인하세요.
