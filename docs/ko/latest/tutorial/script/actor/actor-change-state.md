# 액터 상태 전환

## 기능 설명
지정한 액터의 상태를 전환합니다. 안전한 상태 프레임을 제공할 수 있는 캐릭터는 이전 화면과 새 화면을 실제로 블렌딩하고, 그 외 캐릭터는 페이드아웃, 상태 적용, 페이드인 방식으로 자동 대체됩니다. 전환이 끝나면 스토리 실행을 계속합니다.

## 문법 구조

```text
actor change <캐릭터 이름> <새 상태>
```

## 매개변수 설명

| 매개변수 | 필수 | 예시 | 설명 |
|------|------|------|------|
| 캐릭터 | 예 | kona | 상태를 전환할 액터 이름 |
| 새 상태 | 예 | happy | 전환할 새 상태 |

## 예시

```text
actor change kona happy
```

## 상태 전환 효과

`actor change`는 전환 방식을 자동으로 선택합니다.

1. 현재 및 대상 상태 프레임을 제공할 수 있으면 프리멀티플라이드 알파 셰이더로 픽셀을 블렌딩합니다.
2. 안전한 상태 프레임을 제공할 수 없으면 현재 액터를 페이드아웃하고 상태를 적용한 뒤 페이드인합니다.
3. 전환이 끝난 뒤 다음 스토리 명령을 실행합니다.

`KonadoStageController` 노드의 인스펙터에서 전환을 설정할 수 있습니다.

| 속성 | 기본값 | 설명 |
|------|--------|------|
| `actor_state_transition_enabled` | `true` | 액터 상태 전환의 페이드 효과를 활성화합니다 |
| `actor_state_transition_duration` | `0.3` | 전체 전환 시간(초)이며, 안전 대체 경로에서는 페이드아웃과 페이드인에 절반씩 사용됩니다 |

`actor_state_transition_enabled`를 끄거나 `actor_state_transition_duration`을 `0`으로 설정하면 상태가 즉시 전환됩니다.

전환은 캐릭터 씬을 복제하지 않습니다. 포함된 AnimatedSprite2D 예제는 순수 텍스처 상태 프레임으로 실제 블렌딩을 수행합니다. 사용자 상태 프레임은 일부 표시 요소만이 아니라 캐릭터 전체 화면을 나타내야 합니다. 비디오, Spine, Live2D 및 완전하고 안전한 상태 프레임을 제공할 수 없는 사용자 씬은 자동으로 대체 경로를 사용하므로 스크립트, 오디오 및 동적 미디어가 두 번 실행되지 않습니다. 대상 액터가 없거나 상태를 적용할 수 없는 경우에도 명령을 완료하고 스토리를 계속합니다.
