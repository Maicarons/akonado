# Godot 내장 KonadoScript 편집기

Konado 플러그인을 활성화한 뒤 파일 시스템 독에서 `.ks` 파일을 두 번 클릭하면 `.gd` 파일과 마찬가지로 Godot 스크립트 작업 공간에서 열립니다. KonadoScript는 하단 독 대신 Godot 기본 코드 편집기와 문서 탭을 사용합니다.

## 편집 기능

- Godot 스크립트 문서 탭에서 `.ks`, `.gd` 및 기타 스크립트를 함께 편집
- `.ks`를 편집할 때 왼쪽 위 스크립트 목록을 컴포넌트/명령 트리로 전환합니다. 처음 열 때 컴포넌트 영역과 분기 영역의 높이는 2:1이며, 제목 오른쪽의 슬라이드 스위치로 모든 그룹을 펼치거나 접을 수 있습니다. 접은 뒤에도 최상위 분류는 유지됩니다. 항목을 선택해 해당 구문을 삽입하고 왼쪽 아래 멤버 개요는 분기 탐색용으로 유지합니다
- 온라인 문서에서 편집기 언어에 맞는 `2.4 LTS` 또는 `latest` 문서를 엽니다. `.ks` 편집 중에는 KonadoScript를 지원하지 않는 Godot API 도움말 검색을 숨기고, 다른 스크립트 언어로 전환하면 Godot의 기존 인터페이스를 복원합니다
- 현재 시나리오에 언어 변형이 있으면 온라인 문서 옆의 선택 목록에서 기본 버전과 발견된 현지화 스크립트를 직접 전환합니다
- 실행 취소와 다시 실행, 저장되지 않은 상태, 외부 변경 및 닫기 확인을 Godot가 통합 관리
- 스크립트 편집기의 찾기 및 바꾸기, 줄 이동, 확대/축소, 북마크 및 단축키 사용
- 파일 시스템의 만들기 메뉴에서 유효한 초기 내용을 포함한 KonadoScript 생성
- 멤버 개요에서 `branch` 선언을 확인합니다. 분기, 변수, 신호에서 정의로 이동, 참조 찾기 및 안전한 이름 변경을 지원합니다
- 배경, 배우, 상태, 동작, BGM, 효과음, 음성, 카메라 설정 또는 `jump` 경로를 Ctrl(macOS에서는 Command) 키를 누른 채 클릭하여 실제 장면, 리소스 또는 대상 KonadoScript를 엽니다. 대상이 여러 개면 선택 목록을 표시합니다
- 명령이나 리소스 식별자에 마우스를 올리면 시그니처, 용도, 확인된 경로 또는 미확인 상태를 표시합니다. 실제 탐색 대상이 있는 범위에만 클릭 가능한 밑줄을 표시합니다
- 컨텍스트 메뉴에서 문서 또는 선택 영역 포맷, 수정 제안, 정의로 이동, 참조 찾기, 안전한 이름 변경을 사용할 수 있습니다. 파일 간 리소스 이름 변경은 먼저 변경 미리 보기를 표시합니다
- 조건 블록과 전체 화면 텍스트 블록을 Godot 들여쓰기 설정에 맞춰 자동 정렬
- 원본 `.ks`에 직접 저장하고 리소스 로더가 컴파일한 런타임 `KonadoShot`을 갱신

## 하이라이트와 코드 자동 완성

`KonadoScriptSyntaxHighlighter`는 Godot의 `EditorSyntaxHighlighter`를 기반으로 하며 플러그인 시작 시 스크립트 편집기에 등록됩니다. 하이라이트와 코드 자동 완성은 `KonadoScriptLanguageCatalog`를 공유하고 유효한 키워드는 파서의 `KonadoScriptToken.KEYWORDS`를 기준으로 합니다. 자동화 테스트가 두 정의의 일치 여부를 확인합니다.

자동 완성은 명령, 하위 명령, 삽입 가능한 구문 템플릿과 함께 현재 명령에서 사용할 수 있는 2.8 이름 있는 매개변수를 제안하며, 이미 입력한 매개변수는 다시 표시하지 않습니다. 또한 프로젝트 리소스에서 KonadoScript 경로, 배우, 상태, 동작, 배경, 오디오 및 카메라를 색인화합니다. 상태와 사용자 지정 동작은 선택한 배우에 맞게 필터링되며, 공백이 포함된 따옴표 텍스트 뒤에서도 음성을 완성할 수 있습니다. 현재 문서의 분기, 변수와 신호도 즉시 제안합니다. 이름 있는 매개변수는 별도로 강조되고, 형식, 범위, 충돌과 중복 ID는 정식 컴파일러가 최종 검증합니다. 하이라이트 표현식은 한 번만 컴파일되며 각 줄에는 색상이 바뀌는 위치만 기록됩니다.

기본 하이라이트 리소스 위치:

```text
res://addons/konado/editor/script_editor/konado_script_highlighter.tres
```

다른 `CodeEdit`에서도 하이라이터를 직접 사용할 수 있습니다.

```gdscript
set_syntax_highlighter(KonadoScriptSyntaxHighlighter.new())
```

## 실시간 진단

입력을 잠시 멈추면 Godot는 KonadoScript 언어 브리지를 통해 런타임 `KonadoShot`을 생성하지 않고 어휘, 구문 및 의미 분석을 실행합니다. 오류와 경고는 해당 소스 줄과 스크립트 편집기 내장 문제 패널에 표시되며 Godot 편집기 언어에 따라 중국어 또는 영어를 사용합니다. 여러 줄의 독립된 오류를 한 번에 보고하며, 불필요한 인수, 잘못된 숫자나 불리언 값, 유효하지 않은 점프 경로, 알 수 없는 리소스 ID, 누락된 대상 파일, 배우 수명 주기 및 현지화 스크립트 구조를 검사합니다. 잘못된 입력으로 실시간 분석이 멈추지 않습니다.

오류 범위 위에 마우스를 두면 내용에 맞춰 너비와 높이가 조절되는 진단 카드가 표시됩니다. 진단은 가능성이 높은 순서대로 최대 3개의 시도 제안을 제공할 수 있습니다. 사용자의 판단이 필요한 선택지는 모든 안전한 빠른 수정 적용에서 제외됩니다. 자동 수정할 수 없는 문제에는 리소스 설정이나 문서로 가는 동작이 표시됩니다. 수정은 한 번에 되돌릴 수 있는 작업으로 적용되며 캐럿, 선택 영역, 다중 캐럿, 접기, 스크롤 위치를 유지합니다.

문제를 클릭하면 관련 위치로 이동할 수 있습니다. 기존 파일에 구문 오류가 있어도 스크립트 편집기에서 열고 수정할 수 있습니다. 저장 후에는 리소스 로더가 정식 컴파일을 수행하므로 실시간 진단이 최종 로드 결과를 대체하지는 않습니다.

## 런타임 디버깅

Godot 중단점으로 KonadoScript 실행을 제어할 수 있습니다. 중단점에 도달하면 해당 `.ks` 줄이 열리고 현재 샷, 노드, 영구 변수, 임시 변수가 표시됩니다. 디버거 탭에는 계속, 단계 실행, 다음 줄에서 일시 정지 기능이 있습니다. 릴리스 내보내기에서는 편집기 디버깅 세션이 활성화되지 않습니다.

## 단축키

| 동작 | Windows / Linux | macOS |
| --- | --- | --- |
| 저장 | `Ctrl+S` | `Command+S` |
| 현재 탭 닫기 | `Ctrl+W` | `Command+W` |
| 찾기 | `Ctrl+F` | `Command+F` |
| 찾기 및 바꾸기 | `Ctrl+H` | `Command+Option+F` |
| 줄로 이동 | `Ctrl+L` | `Command+L` |
