# Open-source licenses

Konado uses a multi-license model. When using or redistributing Konado, choose any one of the following licenses for your project:

- [MIT License](https://github.com/godothub/konado/blob/main/LICENSE): the fewest restrictions, suitable for typical commercial and open-source projects
- [BSD 3-Clause License](https://github.com/godothub/konado/blob/main/LICENSE-BSD): additionally prohibits using copyright holders' or contributors' names to endorse derived products
- [Mulan PSL v2](https://github.com/godothub/konado/blob/main/LICENSE-MULANPSL): includes an explicit patent grant

## Redistribution

Retain the copyright notice, license text, and disclaimer required by the license you select. They can normally be included in a third-party notices file, an About page, or documentation distributed with the product. None of these licenses requires displaying Konado branding on a game's startup screen.

When modifying or redistributing the plugin, also review the separate licenses of fonts, images, and other third-party assets in the project. This page summarizes the repository's licensing model and is not legal advice; the selected license text controls.
