# Konado .NET API

Konado .NET API is the C# extension layer for Konado.

It provides:

- The `KonadoApi` autoload entry point
- `DialogueManagerApi` runtime control
- Konado dialogue flow event listeners
- KonadoScript localization path resolution and loading
- Dialogue-variable and save management
- `.ks` script compilation
- Runtime-data wrappers such as `KonadoShot`, `KonadoProgram`, and `KonadoInstruction`

Read the installation guide first, then the API reference.
