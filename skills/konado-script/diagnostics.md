# 静态诊断与快速修复

KonadoScript 2.8 使用与 Godot 编辑器、VS Code 扩展相同的编译与项目索引语义。诊断代码是稳定的机器标识；面向用户的消息会跟随编辑器语言显示。

## 语法与结构

- 检查未闭合字符串、未知语法、缺失操作数和无效运算符。
- 检查 `if` / `else` / `endif`、`screentext { ... }` 等块结构。条件块允许嵌套。
- 检查 `choice "文本" -> branch_id`、`jump`、`jump_branch` 和 `branch` 的结构。
- 检查命名参数的名称、类型、重复项和互斥项；例如对话的 `speed` 与 `interval` 不能同时出现。

## 符号、跳转与控制流

- 检查重复分支、缺失分支和不存在的跨文件跳转目标。
- 检查 `end` 或无条件跳转后的不可达语句，以及永远不会进入的分支。
- 检查临时变量 `$name`、持久变量 `%name` 和字符串插值表达式。
- 项目索引可为分支、变量、演员与资源引用提供定义跳转和引用查询。

## 项目资源

- 检查背景、演员、BGM、音效、语音与相机是否存在于当前项目配置中。
- 区分资源未分配、资源缺失、名称未知和名称重复，避免把配置问题误报成语法错误。
- 检查演员显示、切换状态、移动、播放动作和退出时的生命周期关系。

## 本地化

- 检查默认脚本与本地化脚本之间的结构差异、缺失内容和未翻译内容。
- 本地化诊断不会把允许的文本差异误判为控制流错误。

## 快速修复

编辑器会根据诊断代码生成候选修复，最多优先展示三项高置信度建议。常见修复包括：

- 更正接近的关键字、演员、资源或分支名称。
- 补全缺失的 `endif`、操作数、箭头或引号。
- 创建缺失分支，或跳转到现有分支。
- 移除重复或冲突的命名参数。

快速修复只修改能够明确判断的文本范围；项目资源缺失等需要用户决策的问题会保留为诊断和文档入口。
